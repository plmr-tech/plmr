Консоль для T-Invest API в стиле msfconsole.

Стакан, полная цена сделки и рыночные заявки на Мосбирже — из одного окна.

Каждая заявка разбирается по копейкам: спред, комиссия, задержка.

> [!WARNING]
> Заявки настоящие, на живом счёте — используйте на свой риск.

## ✨ Возможности

- 📖 Стакан с полосками объёма и живой режим `watch` со стрелками ▲▼.
- 💸 `quote` — цена круга «купил и сразу продал»: спред и комиссия брокера по вашему тарифу.
- 🌊 `impact` — средняя цена крупной заявки по стакану.
- 🎯 `buy` / `sell` — рыночная заявка с карточкой и подтверждением словом `yes`.
- 🧾 Разбор исполнения: цена по частям, комиссия, переплата к середине стакана, задержка ответа.
- 📊 `report` — итог по операциям брокера: P&L по цене, комиссии, доля спреда и движения рынка.
- 🗒️ Журнал заявок `journal.jsonl` со снимком стакана в момент отправки.
- 🛡️ Шорта нет: `sell` не продаст больше, чем лежит на счёте.
- ⌨️ Автодополнение по Tab, история команд, красная плашка LIVE для реального счёта.
- 🔐 Сертификат API от УЦ Минцифры подключается только программе, а не в систему.

## 🚀 Сборка

Нужны Windows и Go 1.26.

1. Скопируйте `config.example.yaml` в `config.yaml` и впишите токен.
2. Соберите программу:

   ```
   go build -o plmr.exe ./cmd/plmr
   ```

## ▶️ Запуск

Запускать из папки проекта: `config.yaml`, `certs\` и `journal.jsonl` ищутся в текущем каталоге.

| Команда | Что делает |
| --- | --- |
| `plmr` | Интерактивная консоль |
| `plmr <команда>` | Одна команда без консоли, например `plmr show accounts` |
| `plmr buy SBER --yes` | Заявка без вопроса; без `--yes` — только карточка |

## ⌨️ Команды

| Команда | Что делает |
| --- | --- |
| `use SBER` | Выбрать инструмент; `SBER@TQBR` — с режимом торгов |
| `info` | Лот, шаг цены, UID, FIGI |
| `quote [T]` | Стакан и полная цена круга |
| `impact [T] <сумма>` | Средняя цена рыночной заявки на сумму |
| `watch [T]` | Живой стакан, Enter — выход |
| `buy [T]` / `sell [T]` | Рыночная заявка на `LOTS` лотов |
| `report [T] [YYYY-MM-DD]` | Разбор операций с даты |
| `show accounts\|balance\|options\|journal` | Счета, баланс, параметры, журнал |
| `set LOTS <n>` / `set ACCOUNT <id>` | Параметры сессии |
| `save` | Записать счёт в `config.yaml` |
| `help`, `clear`, `exit` | Служебные |

## 🔑 Секреты (`config.yaml`)

| Поле | Назначение |
| --- | --- |
| `APIToken` | Токен T-Invest API; для торговли — с полным доступом |
| `AccountId` | Номер счёта; пусто — выбрать через `show accounts` |
| `EndPoint` | `invest-public-api.tbank.ru:443`, песочница — `sandbox-invest-public-api.tbank.ru:443` |
| `TLSCACertFile` | Корень УЦ Минцифры: `certs/russian_trusted_ca.pem` |

Токен лучше выпускать на один счёт.

`config.yaml` в репозиторий не попадает.

Образец — `config.example.yaml`.
