# Changelog

## 0.1.0

- Консоль в стиле msfconsole: баннер, автодополнение, история, плашка LIVE.
- `quote`: стакан и полная цена круга — спред и комиссия брокера.
- `impact`: средняя цена крупной рыночной заявки по стакану.
- `watch`: живой стакан.
- `buy` / `sell`: рыночные заявки с подтверждением и разбором исполнения.
- `report`: итог по операциям брокера, журнал заявок.
- Сертификат УЦ Минцифры для API T-Bank подключается только программе.
